## 1. 快速开始

RootLink 是一款 AI 角色陪伴应用，运行于 Android 平台。

**系统要求：** Android 9.0 及以上。

**安装方式：** 下载 APK 文件并安装。

首次启动应用时，会看到一个空白的首页。点击 **「创建角色」** 开始，或先前往 **设置页面** 配置 API Key。

---

## 2. 设置 API

> 在使用 AI 对话功能前，需要先配置 API 提供商和密钥。

### 2.1 进入设置

点击首页右上角的 **⚙️ 齿轮图标**，进入设置页面。

### 2.2 选择提供商

| 提供商 | 默认模型 | 说明 |
|--------|----------|------|
| **MiniMax** | MiniMax-M2.5 | 高性价比选择 |
| **DeepSeek** | DeepSeek-V4-Flash | 更快响应；亦可选 DeepSeek-V4-Pro 获得更高质量 |

在 **「提供商与模型」** 下拉菜单中选择提供商，然后选择具体模型。

### 2.3 填写 API Key

在 **「API Key」** 输入框中填入你的密钥，密钥以密文显示确保安全。

> 获取 API Key：
> - MiniMax：访问 [platform.minimaxi.com](https://platform.minimaxi.com)
> - DeepSeek：访问 [platform.deepseek.com](https://platform.deepseek.com)

### 2.4 调整对话质量

拖动 **「对话质量」** 滑块（0–100），平衡回复速度与质量。

### 2.5 保存

点击页面底部的 **「保存设置」** 按钮。设置即刻生效。

## 3. 创建你的第一个角色

> 每个角色都是一个独立的"灵魂"，拥有自己的记忆、性格和形象。

从首页点击 **「创建角色」** 或底部的 **✦ 创建角色** 卡片，进入五步创建向导。

---

### 第一步 · 基础信息

| 字段 | 说明 |
|------|------|
| **角色标识** | 唯一 ID，创建后不可更改（如 `my-companion`） |
| **模板** | 默认 / 共情 / 克制，影响基础行为 |
| **名称** | 角色的显示名称 |
| **描述** | 一句话概括角色 |
| **卡片配色** | 从 6 种预设颜色中选择：紫藤、鼠尾草、琥珀、玫瑰、雾蓝、橄榄 |

---

### 第二步 · 立绘

角色的"外表"——设定头像和表情立绘。

**头像：** 点击「替换」上传头像图片，圆形裁剪自动适配。

**立绘：** 默认包含 5 种情绪：

| 情绪 | 说明 |
|------|------|
| 默认 (Neutral) | 平静状态 |
| 开心 (Happy) | 笑容 |
| 难过 (Sad) | 悲伤 |
| 生气 (Angry) | 愤怒 |
| 惊讶 (Surprised) | 目瞪口呆 |

点击「更多表情」展开全部选项。选择一种情绪后，点击 **「更换立绘」** 上传对应图片。

**抠图系统：** 上传立绘后，系统自动识别背景色并移除背景。详见 [立绘与抠图](#4-立绘与抠图)。

---

### 第三步 · 人格

| 字段 | 说明 |
|------|------|
| **年龄** | 可选，角色年龄 |
| **性别** | 未知 / 女 / 男 / 其他 |
| **生日** | YYYY-MM-DD 格式 |
| **背景** | 角色经历与身份描述 |
| **语言风格预设** | 友好 / 冷静 / 自信 / 直接 |
| **特质** | 添加/移除性格标签（如"耐心"、"幽默"） |
| **兴趣** | 添加/移除兴趣标签（如"游戏"、"音乐"） |

---

### 第四步 · 记忆

为角色添加初始记忆，指导其行为与认知：

| 字段 | 说明 |
|------|------|
| **内容** | 记忆文本 |
| **类型** | 情景记忆 / 偏好记忆 / 事实记忆 / 日常摘要 / 月度摘要 |
| **重要性** | 0.0 – 2.0，越高越影响角色行为 |
| **上下文** | 如"初次见面" |

可以添加多条记忆。点击底部 **＋** 按钮新增条目。

---

### 第五步 · 语言风格

精确控制角色的说话方式：

| 设置 | 选项 | 说明 |
|------|------|------|
| **词汇水平** | 简单 / 普通 / 学术 | 决定用词复杂度 |
| **句子长度** | 短 / 中 / 长 / 变化 | 单句信息密度 |
| **感叹频率** | 滑块 0–1 | 使用感叹句的频率 |
| **提问频率** | 滑块 0–1 | 反问或提问的倾向 |
| **省略号频率** | 滑块 0–1 | 话未说完的留白感 |
| **Emoji 使用** | 无 / 少量 / 中等 / 丰富 | Emoji 出现频率 |
| **括号使用** | 无 / 少量 / 中等 | 补充说明的习惯 |
| **记忆影响力** | 滑块 0–1 | 记忆对回复的权重 |

---

点击 **「创建」** 完成。角色将出现在首页的角色列表中。

## 4. 立绘与抠图

> 上传一张简单背景的立绘图片，自动去除背景并对齐到统一画布。

### 4.1 上传与自动抠图

1. 选择情绪标签（如「默认」）
2. 点击 **「更换立绘」**，选择图片
3. 系统**自动检测**四个角落的背景色，移除背景
4. 预览窗口实时显示抠图结果

### 4.2 抠图预设

| 预设 | 适用场景 |
|------|----------|
| **保守** | 主体与背景颜色接近 |
| **标准** | 一般情况，默认推荐 |
| **强力** | 主体与背景反差大 |

选择预设后预览自动刷新。

### 4.3 高级微调

点击 **「高级微调」** 展开更多选项：

| 滑块 | 范围 | 说明 |
|------|------|------|
| **背景清理强度** | 0 – 120 | 越高去除越多像素 |
| **缩放** | 0.5 – 1.5 | 人物在画布中的大小 |
| **横向偏移** | -120 – 120 | 水平位置的微调 |
| **纵向偏移** | -120 – 120 | 垂直位置的微调 |

## 5. 聊天交互

### 5.1 进入聊天

在首页点击角色的 **「开始对话」** 按钮，进入聊天页面。

### 5.2 普通模式

- 消息以对话气泡形式呈现
- AI 回复逐句逐字显示，模拟真实的打字节奏
- 输入框输入文字，点击发送或按回车发送

### 5.3 沉浸模式

点击顶部的模式切换按钮进入沉浸模式：

- **全屏立绘**：角色的立绘占据主画面，根据 AI 回复的情绪自动切换表情
- **毛玻璃对话卡片**：文字以打字机效果逐字呈现
- 点击卡片**跳过动画**直接显示完整文本
- 再次点击**进入下一段**对话

### 5.4 表情联动

AI 回复会根据内容自动标注情绪标签（平静、开心、难过、生气、惊讶），对应立绘会自动切换，让角色"活"起来。

## 6. 管理与维护

### 6.1 编辑角色

在首页长按角色头像，或点击角色卡片的 **✏️ 编辑** 按钮，进入编辑模式（五步向导），修改后点击 **「保存」**。

### 6.2 删除角色

在首页点击角色卡片的 **🗑️ 删除** 按钮（需至少保留一个角色）。删除操作不可撤销。

### 6.3 导出角色包

点击角色卡片的 **📤 导出** 按钮，生成 `.amadues` 角色包文件，可用于备份或分享。

### 6.4 导入角色包

在首页点击 **「导入角色」**，选择 `.amadues` 文件即可添加角色。如角色 ID 已存在，可选择覆盖。

### 6.5 深色/浅色模式

点击首页顶部的 **☀️/🌙 按钮** 切换主题。
